Hall of Mirrors — User Guide

Hall of Mirrors turns a photo (or a built-in pattern) into kaleidoscopic, fractal, and conformal art. You build an effect by stacking coordinate “folds” and choosing a renderer that reflects and recurses the result, then dress it with color, framing, and motion. Everything runs live on the GPU — nothing is uploaded.

The idea in one picture

SOURCE          FOLD STACK              RENDERER          GLASS           MOTION
image   →   fold₁ → fold₂ → …  →   Panes/Droste/… →   color/frame →   animate

Read it left to right. Each fold bends the coordinate grid; folds compose in order, so the same folds in a different order give a different result. The renderer mirrors/repeats that bent grid into the final structure. Glass handles color and framing. Motion animates it for video.

Best habit: add one fold, see what it does, then add the next. Stacks of 2–4 folds already go a long way.

Quick start

  • Source: Load image for your own photo, or pick a built-in pattern (orbs, plasma, rings, stripes, waves, voronoi, truchet, halftone, or a grid/polar/checker probe) and shape it with the Scale / Hue / Variation knobs to learn an effect against a clean reference.
  • Renderer: start on Panes.
  • Fold stack: pick an operator in the add dropdown and click +. Try Polar fold first — instant kaleidoscope.
  • Drag its sliders; add a second fold (Swirl or Spiral).
  • Open Presets to see full recipes. Export PNG when happy, or Record / HQ Video for animation.

Renderers

The renderer decides how the folded plane is reflected and repeated. Same stack + different renderer = very different image, so switch often.

Shared controls: Depth (reflection/recursion steps), Step scale (zoom per level), Twist (rotation per level), Shift X/Y & Zoom (pan/zoom), mirrored (flip alternating tiles), and Feedback amount (trail length, Feedback renderer only).

The fold stack

  • Add from the dropdown; it appends to the bottom.
  • Reorder with ↑/↓ — order matters (Swirl-then-Mirror ≠ Mirror-then-Swirl).
  • Remove with ×.
  • Numeric params are sliders; choice params are dropdowns (mode, style, symmetry group…).
  • Mode-aware: multi-mode folds show only the current mode’s parameters.
  • Origin (⊕): click it and drag on the canvas to place that fold’s center — great for off-center swirls and lenses.

The big multi-mode banks

  • Complex — up to four complex functions in sequence (1/z, z², sqrt, exp, log, the trig/hyperbolic families and their inverses), with per-axis frequency and optional mirror.
  • Complex sum — instead of chaining, add functions with individual weights: a pre-conditioner tier (reciprocal, log, sqrt, exp) plus a 15-function sum tier, with an input affine.
  • Wave bank — one fold, 17 wave styles (waves22, dc_gnarly’s 8 nested-trig modes, vibration2, waves2b Jacobi/Bessel, waves_julia/spiral/noise/mobius/power/fisheye/swirl…). Pick Style; only that style’s knobs show. Weight blends; Seed feeds input back.
  • Lazy — the classic lazy-susan family: Susan (circular swirl, movable center via x/y), Travis (square swirl), Jess (n-gon swirl), plus a Sensen post-fold. For Travis/Jess try Amount ≈ 0.5–0.6 to stay in frame.
  • Loonie — circle-inversion bubbles: Loonie (circle), Loonie2 (n-gon/star/circle blend), Loonie3 (parabolic). Radius sizes the bubble independently of Amount; Rotate spins the Loonie2 polygon.
  • BusyBrad — the grid version of the lazy family: tiles the plane (Grid size), each cell a Susan/Jess/Combined swirl, with Spin/Twist/Space/N and a Sensen fold. Grid size 0 = a single centered swirl.

Recolor

Counterchange is the one fold that changes color, not geometry: it splits the plane into stripes/checker/pinwheel/rings and recolors alternating regions (negate, hue 180°, desaturate, tint). Use Cell for scale, Angle° for orientation. (The Glass panel has a second, global counterchange.)

Glass — color & framing

  • Frame / Frame width — border vignette-frame.
  • Tint — color + blend amount.
  • Counterchange (global) — off / negate / hue 180° / desaturate / tint, with a fold scale.
  • Chroma — chromatic-aberration fringing. Ripple — final rippling pass. Vignette — darken edges. Grain — film grain. Hue / depth — shift hue with recursion depth.

Motion — animation

  • Drift slowly evolves fold parameters. Spin rotates the whole view. Rotate is a fixed (animatable) rotation. Wobble gently undulates the whole pattern over time — it animates every fold, plus the Wave folds and Ripple.
  • Loops are built to close seamlessly when exported as HQ Video.

Presets, export & recording

  • Presets: load a factory recipe, save your own, Randomize, Reseed, and Copy/Paste or Import/Export as text to share.
  • Export PNG at 1×/2×/4×; HQ Still for a super-sampled frame.
  • Record (WebM) captures the live canvas; HQ Video renders offline frame-by-frame (loops close exactly, Feedback rebuilt at full res).
  • Aspect locks the composition to any common ratio before export.

Recipes to try

  • Kaleidoscope portrait: Polar fold (6–12) → Swirl (small) → Panes + Tint.
  • Infinite vortex: Spiral → Droste, raise Step scale & Twist.
  • Stained glass: Wallpaper (p6m) → Counterchange (checker, tint) → Panes.
  • Liquid chrome: Wave bank (dc_gnarly) → Feedback, add Chroma + a little Drift.
  • Bubble field: Loonie (Loonie2, sides 6, some Star) → Spherical → Room.
  • Spiral galaxy: Log spiral → Wave bank (waves_spiral) → Droste, Vignette up.
Muddy? Remove the last fold — over-stacking is the usual culprit. Flat? Switch the renderer before adding more folds.
